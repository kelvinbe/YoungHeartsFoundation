# Young Hearts Foundation

A responsive Next.js + Chakra-ready-inspired nonprofit landing page for an organization supporting children experiencing homelessness.

## Stack

- Next.js 16
- React 19
- TypeScript
- Lucide React
- Custom responsive CSS
- Google Fonts: DM Sans + Playfair Display

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Design direction

The layout follows the supplied reference: a slim yellow utility bar, clean navigation, large photographic hero, three service cards, editorial story section, volunteer banner, impact metrics, campaign cards, donation CTA and a dark-green footer. The copy, brand, colors and imagery are original for Young Hearts Foundation.

## Notes

The sample photography is loaded from Unsplash at runtime. Replace the URLs in `components/Section.tsx` with your own approved organization photography before production.
